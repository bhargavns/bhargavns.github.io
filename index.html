Research

My research centres on model efficiency and data efficiency: getting strong performance from compact models trained on modest datasets. Rather than relying on scale, I ground a model's decisions in structured evidence drawn from outside its training data, which makes it cheaper to run, faster to train, and easier for people to check.

Efficient models for language documentation

Linguists documenting endangered languages annotate each word by hand, splitting it into morphemes and labelling each one, as in the sentence above. It is a demanding test of efficiency: each new language comes with only a few hundred annotated sentences. I have built a line of compact models for this setting — a morpheme representation that cut training and inference time by over 90%, and a retrieval-augmented system in which large language models use descriptive grammars to correct a compact model. The latest of these, CWoMP, retrieves glosses from a lexicon that linguists can edit: it needs up to 8.5 times fewer FLOPs than the previous state of the art and, by design, cannot invent morphemes.

Tools built with the people who use them

A model that scores well on a benchmark is not necessarily useful to the people documenting a language. I have worked directly with communities and linguists documenting Zapotec, Totonac, Tulu and Kazakh. GlossAssist puts CWoMP into a real annotation workflow: every analysis a linguist confirms is added to the lexicon, so the model improves from expert corrections without retraining. I also designed a user study that measures annotation time, quality, workload and trust.

Agents that learn from perception and interaction

My current project, ALKoG (Agent Learning and Knowledge Grounding), tests whether grounding still works when evidence comes from seeing and acting rather than from text. Agents perceive a simulated world through Segment Anything, act through policies trained with PPO, and build a knowledge graph of objects, relations and the outcomes of their actions. It asks four questions:

  1. Can agents form concepts from raw views that stay stable across viewpoints and episodes?
  2. Does structured memory let them learn tasks in fewer interactions and transfer to new layouts?
  3. When agents coordinate, does their communication develop structure linguists would recognise?
  4. Can a newcomer learn an existing communication system from limited interaction?

Data-efficient language learning

For BabyBabelLM, I helped curate developmentally plausible training data across 45 languages and built an evaluation suite for multilingual linguistic competence. Compact models trained on this data show that formal and functional language abilities develop at different rates under a fixed data budget.

Where this is going

Relational world models for sample-efficient agents
Turning ALKoG's knowledge graph from memory into a predictive model of how actions change a scene, so agents can plan before acting and transfer to unseen combinations of objects.
Agents that improve from human correction
Letting people edit an agent's explicit memory to fix systematic errors without retraining — from simulated environments to evidence-extraction agents working over long clinical records.
Learning to communicate from limited interaction
Measuring how grounded structure reduces the interaction a newcomer needs to learn a shared language — towards agents that can pick up a team's conventions from a handful of exchanges.
